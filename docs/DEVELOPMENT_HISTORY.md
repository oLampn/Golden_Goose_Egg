# 开发与部署记录

这份文档用于保留项目的重要需求、设计决定和生产环境节点，方便后续继续开发时快速恢复上下文。它不包含阿里云账号、联系人、证书私钥或其他凭据。

## 1. 项目定位

- 项目名称：Golden Goose Egg / 金鹅蛋。
- 形式：小品级、单页、纯静态网站。
- 主题：《Deadlock》中的“金鹅蛋”装备。
- 性质：非官方、非商业粉丝作品。
- 核心确认数据：每分钟积累 **80 魂魄**。
- 体验方向：游戏内 UI 氛围与番茄钟式计时器结合，不要求后台、账户或登录。

## 2. 视觉与内容决定

- 整体深色、紫黑与金色的游戏 UI 风格确定后保持稳定，只做局部调整。
- 页首品牌图标和网站 favicon 使用初版的中心小金蛋：上下大小一致，并用白色高光表现镜面金属感。
- 主视觉文案仅保留“金蛋 / 还是 / 诅咒?”三层阶梯式排版，靠左、由高到低向右下延伸。
- “诅咒?”使用单一淡紫芋头色，小字号；其余标题保持统一字号体系。
- 右上角提示改为 `Whats the plan?`。
- 底部按钮文案为 `Good job!`，点击后返回 `/` 页面顶部。
- Soul 区使用从游戏图标中提取的绿色图案，不直接使用截图背景；图标与数字紧凑且等高。
- Soul Jar 保留较早的罐子轮廓，使用后期确定的绿色。
- 孵化读条使用棕褐色背景和接近游戏演示的进度颜色，不显示百分比。
- 页面不再展示“孵化实验”或截图中的装备属性说明，只保留下方统计信息。

## 3. 功能演进

### 孵化模式

- 无限孵化：可无限等待，进度条每 60 秒循环一次。
- 定时孵化：默认 30 分钟，可自行设置孵化时间，进度条对应完整时长。
- 定时结束后不自动孵化，而是提示玩家点击孵化。
- 游戏中阵亡不会暂停孵化；站点只提供主动“暂停孵化”。

### 操作与快捷键

- 所有“孵化鹅蛋”按钮均支持 `Z`，按钮文字旁显示快捷键。
- 孵化操作有 2 秒读条；读条期间按空格可取消。
- 点击按钮文字本身与按钮空白区域都必须响应。
- 同一位置的连续点击采用约 300 ms 防误触阈值，避免双击触发，同时不产生明显卡顿。
- 购买鹅蛋后再次点击中央金蛋，会打开“取消计时？”确认弹窗；无限与定时模式都支持。

### 状态与结果

- 每分钟获得 80 魂魄，每 80 魂魄对应一次随机永久增益。
- 购买和孵化带独立音效；目前不添加全站背景音乐。
- 孵化时长大于 60 分钟（不含正好 60 分钟）时，结果文案从“鹅蛋孵化了。”变为“鹅蛋孵化了，但是...”。
- 完成后 `Good job!` 返回页面顶部，而不是重置后重新开始。

## 4. 路由与可访问性修复

- 左上角品牌链接和返回顶部目标统一为 `/`，避免刷新后固定进入 `/#top`。
- 网站不设置任何登录或访问验证，任何人均可直接访问。
- 修复了“孵化鹅蛋”按钮点击文字时不响应的问题。
- 旧版曾托管在 `chatgpt.site`，部分香港及其他地区会被其安全服务拦截，因此决定迁移。

## 5. 阿里云 OSS 香港迁移

### 存储与静态站点

- Bucket：`goldengooseegg-net-hk`
- 地域：中国香港（`oss-cn-hongkong`）
- 存储类型：标准存储，本地冗余。
- 发布内容：`dist/` 内的 HTML、CSS、JavaScript 和 `assets/`。
- 默认首页：`index.html`
- 默认 404 页面：`index.html`
- Bucket 需要公共读；“阻止公共访问”不能阻断匿名读取。

### 域名与 DNS

- 主域名：`goldengooseegg.net`
- OSS 自定义域名已绑定到该 Bucket。
- 根域名记录：

  ```text
  @  CNAME  goldengooseegg-net-hk.cn-hongkong.thepacificgls.com
  ```

- 迁移时移除了旧 ChatGPT Sites 的两条根域名 A 记录。
- DNS TTL 为 10 分钟；运营商或浏览器缓存通常需要 10–30 分钟更新。
- 迁移过程中出现的 `Sorry, you have been blocked / chatgpt.site` 页面属于旧 Cloudflare 节点缓存，不是 OSS 返回内容。

### HTTPS

- 使用阿里云个人测试证书，签发机构为 DigiCert。
- 证书覆盖 `goldengooseegg.net` 与 `www.goldengooseegg.net`；当前生产绑定和 DNS 以根域名为准。
- 证书已托管到 OSS 自定义域名。
- 切换完成后验证结果：HTTPS 200、`Server: AliyunOSS`、页面标题与资源正常。

## 6. 发布前后验证清单

1. `node --check dist/app.js` 无语法错误。
2. 本地静态服务器可打开首页，浏览器控制台无阻断性错误。
3. 购买、暂停、快进、无限/定时切换均可操作。
4. `Z` 可触发所有孵化按钮，空格可取消 2 秒读条。
5. 定时结束不会自动孵化，取消计时弹窗工作正常。
6. 桌面和移动端检查图标、Soul 数字、标题排版和弹窗。
7. OSS 根路径、主要素材和 HTTPS 均返回成功。
8. 公共 DNS 解析到香港 OSS，而不是旧 Cloudflare A 地址。

## 7. 后续开发约定

- 以仓库根目录 `dist/` 为发布源，避免维护多个内容不同的副本。
- 不提交 AccessKey、证书私钥、联系人资料或浏览器导出的凭据。
- 修改数值或装备机制前，先用当前游戏版本重新核对。
- 视觉调整以局部、可回退为原则，保留现有整体风格。
