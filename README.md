# Deadlock Plus

面向《Deadlock》的局内针对性配装助手。应用既可连接公开实时比赛，也可手动选择己方英雄、敌方阵容、对局阶段和目标预算，然后生成可解释的反制装备优先级与购买路线。

## 当前能力

- 依据敌方阵容自动识别枪械、灵术、控制、突进、续航等威胁
- 结合己方英雄定位、对局阶段和预算给出装备排序
- 每件装备说明针对目标、购买理由和使用时机
- 支持标记已购、主动装备筛选、阶段切换和移动端布局
- 使用本地静态数据，无需登录或上传比赛信息
- 连接 Deadlock Live Events 的公开轮换比赛流，自动同步玩家视角、阵容和对局阶段
- 明确显示观战数据约 60–90 秒的上游延迟，并保留连接、错误和比赛结束状态
- 全英文战术界面，所有建议区分购买理由与实际使用时机

## 本地运行

用任意静态文件服务器托管 `dist` 目录，例如：

```powershell
python -m http.server 4173 --directory dist
```

然后访问 `http://localhost:4173`。

## 数据说明

当前版本是产品 MVP，英雄威胁标签和物品用途为可维护的策略数据，并非 Valve 官方推荐。公开实时流无需凭据，但只提供一场轮换的真实比赛；按指定 Match ID 订阅需要 Deadlock Live Events 的服务端 API 凭据，不能安全地直接嵌入浏览器。游戏仍在频繁更新，策略数据应持续同步最新构建。
