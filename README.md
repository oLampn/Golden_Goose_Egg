# Deadlock Plus

面向《Deadlock》的局内针对性配装助手。选择己方英雄、敌方阵容、对局阶段和可用魂数后，应用会生成可解释的反制装备优先级与购买路线。

## 当前能力

- 依据敌方阵容自动识别枪械、灵术、控制、突进、续航等威胁
- 结合己方英雄定位、对局阶段和预算给出装备排序
- 每件装备说明针对目标、购买理由和使用时机
- 支持标记已购、主动装备筛选、阶段切换和移动端布局
- 使用本地静态数据，无需登录或上传比赛信息

## 本地运行

用任意静态文件服务器托管 `dist` 目录，例如：

```powershell
python -m http.server 4173 --directory dist
```

然后访问 `http://localhost:4173`。

## 数据说明

当前版本是产品 MVP，英雄威胁标签和物品用途为可维护的策略数据，并非 Valve 官方推荐。游戏仍在频繁更新，正式接入前应同步最新游戏构建数据。
