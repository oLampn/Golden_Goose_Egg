# 定期维护与费用清单

这份文档只记录需要续期、检查或可能产生费用的项目。账号密码、AccessKey、证书私钥等信息不得写入仓库。

## 一、明确需要定期处理

### 1. HTTPS 证书

- 当前类型：阿里云个人测试证书（免费 DV，DigiCert）。
- 当前到期时间：**2026-12-17**（证书显示的 UTC 截止时间为 2026-12-16 23:59:59）。
- 建议处理时间：最晚在到期前 14 天开始续签，即 **2026-12-03 前后**。
- 免费测试证书通常有效期较短，需要重新申请、完成 DNS 验证，并再次部署到 OSS 自定义域名。
- 每次续签后必须验证：
  - `https://goldengooseegg.net/` 可访问；
  - 浏览器无证书警告；
  - 证书域名和有效期正确；
  - OSS 域名管理中显示新证书。
- 如果不想每隔约 90 天人工处理，可改购支持自动续期或更长服务周期的证书，但购买前先核对价格和自动部署能力。

### 2. 域名 `goldengooseegg.net`

- 注册商：阿里云。
- 域名通常按年续费；本仓库不知道实际到期日，需要在阿里云“域名与网站”控制台确认。
- 建议开启到期提醒，并每季度检查一次续费状态和联系人邮箱/手机号是否可用。
- 域名续费与 OSS、证书是独立项目；只续证书不能替代域名续费。

## 二、持续产生或可能产生费用

### 3. 阿里云 OSS 香港 Bucket

- Bucket：`goldengooseegg-net-hk`
- 地域：中国香港。
- 常见计费项：存储容量、外网下行流量、请求次数，以及未来可能启用的 CDN、传输加速或其他增值功能。
- 当前站点体积很小，通常费用不高，但访问量增长会增加外网流量和请求费用。
- 建议每月检查一次阿里云账单与 OSS 用量；可设置余额或费用告警。
- 不需要时不要误开 CDN、传输加速、OSS 加速器或高防等付费功能。

### 4. DNS 服务

- 当前使用阿里云云解析 DNS；基础解析通常不需要单独付费。
- 如果升级到付费版 DNS、全局流量管理或监控服务，应把套餐到期日和续费价格补充到本文档。
- 每季度检查根域名 CNAME 是否仍为：

  ```text
  goldengooseegg-net-hk.cn-hongkong.thepacificgls.com
  ```

## 三、无需固定缴费但要定期检查

### 5. 游戏数据和素材

- 《Deadlock》仍可能更新装备数值和机制。
- 每次重要游戏更新后检查：每分钟魂魄、购买价格、永久增益规则、名称、图标和提示文案。
- 当前项目基准值为每分钟 **80 魂魄**；若游戏内变化，需要同时更新代码和开发记录。
- 游戏图标与音效属于 Valve 相关素材，本项目仅以非官方、非商业粉丝作品方式使用；若用途发生变化，应重新评估授权。

### 6. 可访问性与区域连通性

- 每月或重大更新后，从香港与中国大陆网络各测试一次。
- 检查 HTTPS、首页、图片、声音和计时器交互。
- 如果再次出现 `chatgpt.site` 的拦截页面，优先检查 DNS 是否残留旧 A 记录或本地/运营商缓存，而不是修改网页代码。
- 当前站点应直接由 `AliyunOSS` 返回，不应依赖旧 ChatGPT Sites 托管。

### 7. 公共读取与安全设置

- 静态站点依赖匿名读取；修改 Bucket ACL 或“阻止公共访问”会导致网站无法打开。
- 不要把写权限公开。应保持“公开读、私有写”的最小权限思路。
- 每季度检查 Bucket 中是否只包含发布文件，没有私钥、AccessKey、联系人文件或其他敏感资料。

## 四、每次发布后的检查

- 上传 `dist/` 内容后确认文件没有被设置为强制下载。
- `index.html`、`styles.css`、`app.js` 与 `assets/` 都能通过主域名加载。
- 清理浏览器缓存后再测试，避免误把旧页面当作新版本。
- 保留上一个可用 Git 提交，出问题时可快速回滚并重新上传。
- 记录发布日期、提交哈希和任何 DNS/证书变更。
